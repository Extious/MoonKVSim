# Fidelity gaps

This registry is fail-closed. The current delivery is CPU metadata-only
GlobalDES and has an E2 evidence ceiling. `closed at E2` means a bounded
simulator-semantic differential passed; it never means calibrated hardware,
physical validation, or paper readiness.
