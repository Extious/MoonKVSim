\subsection{KV Placement Planner: Budgeted Admission}
\label{sec:capacity-allocation}

\paragraph{A foreground-bounded budget.}
The Peer region borrows capacity from the target's KV pool. At each
placement window, the Adapter reports a recent foreground high-water
mark and headroom for possible admissions within the next window.
With configured cap $B_{\mathrm{cap}}$ (default 4\,GiB), the budget is
\begin{equation}
 B=\max\{0,\min(B_{\mathrm{cap}},\ \mathrm{pool}-\mathrm{watermark}
                      -\mathrm{headroom})\}.
 \label{eq:peer-budget}
\end{equation}
The planned budget stays fixed within the window; an emergency pressure
event can trigger immediate reclamation (Section~\ref{sec:kv-runtime}).

\paragraph{Whole-footprint admission.}
Algorithm~\ref{alg:placement} processes requests by increasing slack,
breaking ties by stable request ID. Tier-D/P requests retain all sealed
KV and required selector state in DRAM. For Tier P, the Planner constructs
the entire front-layer hot-set footprint, including selector state.
It admits the set if its incremental physical bytes fit; otherwise it
skips that request and continues to later requests, which may be smaller.
Shared objects are counted once. This greedy rule need not maximize total
WCT improvement or fill every free byte.

Sorting costs $O(n\log n)$ for $n$ active requests. The layer-prefix
calculation is $O(N)$; per-layer rankings are cached after the ranking
window. Physical occupancy is checked separately during reconciliation:
copying, committed, and reclaiming bytes remain charged until release
completes. A lower target budget does not immediately free addresses.

Across windows, slack changes tiers/order, context and available capacity
change admission, and rankings change object identities. The Adapter
executes only the difference from the committed plan. Existing committed
objects are not recopied. Planner estimates use representative-concurrency
costs; bandwidth and concurrency sweeps remain necessary to test their
accuracy under simultaneous retries.
