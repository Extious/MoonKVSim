\subsection{System Overview}
\label{sec:system-overview}

Figure~\ref{fig:system-overview} separates applications, control, and
inference engines. Applications report request/workflow IDs and DAG
updates. The Router dispatches by load and locality; the AegisKV
Controller owns slack, recovery assignments, and backup policy.
Each DP's Adapter controls local Peer capacity and resident layer
counts, and invokes its Connector to move KV directly between engines
and storage. Badges index the mechanisms below, not execution order.

The Recovery Manager records a request's retry target and Peer DP rank
at arrival (\S\ref{sec:recovery-manager}). The KV Manager refreshes
backup policy on request/KV/slack events and control windows
(\S\ref{sec:kv-manager}); each target Adapter updates its budget and
layer prefixes every window (\S\ref{sec:kv-runtime}). The Controller
retains directory and commit metadata outside the source's failure domain.
