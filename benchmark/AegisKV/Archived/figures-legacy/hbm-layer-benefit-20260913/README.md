# HBM 初始驻留层数、单层计算/传输时间与收益

这是解析模型与可复算图，不是实验测量或已实现的执行器性能。未启动任何 GPU、H2D 或推理测量。

问题：已有 M 个历史 token 的有效 KV；N 个后缀 token 需要重新做前向。恢复目标 GPU 在起点拥有前 k 层的历史 KV，其余层的历史 KV 在 Host。改变 k 以及单层计算 C 与单层 H2D 时间 D，会怎样改变从起点到最后一层前向完成的耗时？

## 定义与边界

- L=36，用于对应 [Qwen3-8B 官方配置](https://huggingface.co/Qwen/Qwen3-8B/blob/main/config.json) 的 num_hidden_layers=36；32 是 num_attention_heads。该配置于 2026-09-13 核对。未给 Qwen3-8B 赋予任何实测 C/D。
- C：以 M 个历史 token 为前缀，对 N 个后缀 token 做完整的单层前向，包括 Attention 和 FFN。不是只做 K/V 投影的时间。
- D：M 个历史 token 的单层 K、V 从 Host 到目标 HBM 的时间。
- k：**连续前 k 层**在时间零已经驻留 HBM 的历史 KV。k 不是最终执行 HBM 容量，也不是其他任意 k 层；改变层的位置可能改变收益。
- 相同请求、模型、M 和 N；每个方案依然计算 N 个 token 的全部 L 层，计算工作量 LC 相同。收益是关键路径等待减少。
- 假设每层 C、D 相同；一个计算流、一个串行 H2D 流，可以互相重叠；目的 HBM 与预取空间足够；历史 KV 不必重计算。
- 以完整层为调度粒度，在该层开始前等历史 KV 就绪。实际 K/V 投影可能在历史 KV 到达前开始，其收益不在本模型内。
- 不含故障发现、排队、模型权重加载、跨卡集合通信、算子启动、流同步成本与带宽争用；不是完整 TTFT/WCT 模型。C/D 是理论敏感性参数，不是把硬件参数改变后仍保持其余性能不变的测量结论。
- 5 个 C/D × 37 个整数 k × 2 个预取策略，共 370 个解析取值；无独立重复、置信区间、随机种子或物理实验。连线连接整数 k 的取值。

## 基线和两种预取语义

记 g=max(D−C,0)。k=0 时，第一层先传输，随后各层计算与下一层的传输重叠。两种策略在等时层假设下具有相同基线：

`T0 = D + (L−1) max(C,D) + C = LC + D + (L−1)g`。

图中纵轴为耗时减少比例 `ηk=(T0−Tk)/T0`，越大越好；各 C/D 用自己的 k=0 基线。不是加速比 T0/Tk，也不是重计算 FLOPs 减少比例。

### (a) 严格只预取下一层

计算第 i 层开始时，最多发起第 i+1 层的历史 KV 传输。若前 k 层都在 HBM，第 k+1 层的传输要等第 k 层开始计算才能启动。

对 1≤k≤L：

`Tk,next = kC + (L−k) max(C,D)`

`ΔTk,next = T0−Tk,next = D + (k−1) max(D−C,0)`。

- k 从 0 到 1：省 D。
- 之后每增加一层：省 g=max(D−C,0)。
- C≥D 时，首层消除起步等待后，后续传输已经能被计算掩盖；继续保留更多层不再减少这段延迟。
- D>C 时，首层之后呈线性增长，直至 k=L；D−C 越大，增量斜率越大。D 接近 C 时，后续层收益很小。

### (b) 从起点连续预取未驻留层

时间零就启动第 k+1 层 H2D，之后按层顺序尽早传输第 k+2、k+3……层；不要求它们紧邻当前计算层。需要充足的目的 HBM 与预取空间。

对 1≤k≤L：

`Tk,early = max(LC, (L−k)D+C)`

对 0≤k≤L 的统一收益式：

`ΔTk,early = min(kD, D+(L−1)max(D−C,0))`。

因此收益可先以每层 D 增长，最后一次增加可能仅有部分收益，随后达到计算下限 LC。

`k*early = ceil(1+(L−1)max(1−C/D,0))`。

其中 C/D≥1 时 k*=1；C/D=0.75、0.5、0.25，L=36 时，分别为 10、19、28 层。饱和表示剩余 H2D 都能被该次前向隐藏，**不表示没有传输，也不表示省掉计算**。

图 (b) 的优势依赖预取策略；不能把这个结果当作“仅有逐层依赖”就自然保证的性能。两种策略最终 k=L 都到达 LC。

## 独立递推核对

`plot_benefit.py` 用逐层就绪事件独立核对闭式公式。复制引擎有自己的可用时间，计算流有自己的可用时间；复制完成后该层 KV 才就绪。

对提前预取策略，未驻留的第 j 层复制完成于 jD。计算完成时间满足：

`F0=0; Fi=max(F(i−1),Ri)+C`，其中 `Ri=0`（i≤k），否则 `Ri=(i−k)D`。

对只预取下一层的策略，复制开始还要满足 `copy_start_i >= compute_start_(i−1)`，第一层允许从零开始。

核对使用精确分数，覆盖 L=1/2/3/8/32/36，三种 D 尺度以及 C/D=0、0.1、0.25、0.5、0.75、0.99、1、1.01、2、10。检查闭式与事件递推一致、总计算不变、复制次数为 L−k、收益单调、提前预取不慢于只预取下一层、饱和 k 的最小性。C=0 是数学边界，不是实际 N>0 推理速度。

## 仅供理解的数值例子

**假设** L=36、C=1 ms、D=2 ms；基线 T0=73 ms。

| 初始 HBM 层数 k | 只预取下一层 Tk | 起点连续预取 Tk |
|---:|---:|---:|
| 0 | 73 ms | 73 ms |
| 1 | 71 ms | 71 ms |
| 4 | 68 ms | 65 ms |
| 8 | 64 ms | 57 ms |
| 16 | 56 ms | 41 ms |
| 19 | 53 ms | 36 ms |
| 36 | 36 ms | 36 ms |

C、D 同时乘相同倍数，绝对收益也乘这个倍数，百分比与饱和层数不变。因此比较跨场景的百分比时，C/D 或归一化差 `(D−C)/D` 比只看绝对差 D−C 更充分。
