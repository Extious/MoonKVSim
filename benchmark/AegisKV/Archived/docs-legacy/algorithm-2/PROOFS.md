# 容量租金版 SlackLandlord 的模型内证明

本文件证明 [README.md](README.md) 中模型与参考求解器的性质，不证明原累计租金算法的竞争比，也不证明预测时间等于实机时间。

## 1. 假设与保证的范围

固定一个决策版本，满足：

1. 物理 chunk 构成森林，字节数为正整数；可行集合关于父节点闭合。
2. Agent 的当前执行分支各自绑定到一个工作流 DAG 节点，并引用森林中的一条根到节点路径。
3. 每个场景下的恢复时间表非负，随可用前缀长度单调不增。前缀更长时可以回退到较短的恢复方案。
4. 给定场景下，Agent 的恢复延迟只由它的前缀长度决定，作为非负附加节点时间加入本轮参考 DAG。
5. 场景集合、非负归一化权重、DAG、正常时间和恢复时间表在一次决策内固定。
6. 已固定引用、候选可读性和容量约束可行；否则返回不可行/延后，不能声称找到合法分配。

第 4 条不包含依赖所有备份选择的任意恢复带宽竞争。模型有这种竞争时，需要重新定义目标和有效上界。

以下 F 均为相对同一场景“本 Pool 不提供备份”的 WCT 减少量。因为复制成本被本次范围省略，本文件不对状态切换期间的 WCT 作最优性声明。

## 2. 单 Agent 的 Slack 公式

设一个工作流正常完成时间为 M，所有经过受影响 Agent 节点的路径中，最长正常路径长度为 P。其 Slack 为 \(s=M-P\ge0\)。给该节点增加恢复延迟 T 后：

\[
D(T)=M+[T-s]_+.
\]

证明：经过该节点的每条路径都增加 T；其最长长度变为 P+T。不经过该节点的路径不变。若 P<M，后者中有长度 M 的路径；若 P=M，P+T 已经不小于所有其他路径。因此完成时间均等于 \(\max(M,P+T)\)。

比较无备份和保留前 k 块备份，得到：

\[
U(k)=D(T(0))-D(T(k))
=[T(0)-s]_+-[T(k)-s]_+.
\]

因此，局部收益在 \(T(k)\ge s\) 区域等于恢复时间差，在跨过 Slack 阈值时被截断，在两条路径都被 Slack 吸收时为 0。这个结论仅在单个节点受影响时允许独立使用；多个节点受影响应重新计算整个 DAG。

## 3. 单调性不等于收益递减

**命题 1。** 若 I 和 S 都是合法前缀集合且 \(I\subseteq S\)，则 \(F(I)\le F(S)\)。

证明：对任意 Agent，其在 S 中的前缀不短于在 I 中的前缀，恢复延迟不增。DAG 的最长路径对节点时间单调，因此每个场景、每个工作流的完成时间不增。乘非负权重并求和即可。

**反例：F 不必是次模函数。** 一个工作流中有两个等长并行分支 A/B。不备份时各需恢复 12 ms，备份后各需 8 ms。容量暂不限制，每个 Agent 只用一个独立 chunk：

\[
F(\varnothing)=0,\quad F(\{A\})=F(\{B\})=0,\quad F(\{A,B\})=4.
\]

单独备份 B 的收益为 0；已有 A 时，再备份 B 的收益为 4，呈现互补性。故不能套用依赖收益递减的 Lazy greedy 排序保证或次模近似比。

## 4. 每块恢复时间减少量给出有效上界

定义 Agent a 在场景 f 下第 k 块带来的恢复时间减少量：

\[
\delta_{a,k}^f=T_a^f(k-1)-T_a^f(k)\ge0.
\]

将引用物理 x 的所有相关 Agent/场景的这项减少量按场景权重相加，得到 README 式 (10) 的 \(u_x\)。

**引理 2。** 对任意合法 \(I\subseteq S\)，

\[
0\le F(S)-F(I)\le\sum_{x\in S\setminus I}u_x.
\tag{P1}
\]

证明分三步：

1. 一张 DAG 中，若各节点时间减少 \(e_v\ge0\)，最长路径时间减少不会超过 \(\sum_v e_v\)。任一路径上的减少量不超过这个和，对最大路径取界仍成立。
2. 一个 Agent 的前缀由 i 扩展到 k，其恢复时间减少恰为 \(\sum_{j=i+1}^{k}\delta_{a,j}^f\)，由望远镜求和得到。
3. 因为 I/S 都满足前缀闭合，Agent 增加的每一个前缀位置都在 \(S\setminus I\) 中。将所有 Agent 的减少量求和、再按场景权重求和，得到右侧。共享 x 可在上界中承载多个受益者，但其容量仍只计一次。

这个上界可能很松，例如并行分支的减少不同时作用于关键路径；这不影响有效性。代码中的 upper_values 和 workflow_cap 都是上界，不能用于报告真实的共享 WCT 收益。

## 5. 分数松弛与容量租金

在一个搜索节点，I 为已经决定保留的集合，X 是仍可被选择的物理块，剩余容量为 R。根据引理 2，任何可行补充集合的收益增加不超过：

\[
\max_{0\le z_x\le1,\ \sum b_xz_x\le R}\sum_{x\in X}u_xz_x.
\tag{P2}
\]

式 (P2) 放松了依赖与整数性，只用于上界。对任意 \(\lambda\ge0\)：

\[
\sum_xu_xz_x
\le \lambda R+\sum_x[u_x-\lambda b_x]_+.
\tag{P3}
\]

证明：将 \(u_xz_x\) 写为 \(\lambda b_xz_x+(u_x-\lambda b_x)z_x\)。第一部分受容量约束不超过 \(\lambda R\)，第二部分利用 \(0\le z_x\le1\) 逐项取正部上界。

按密度 \(u_x/b_x\) 从高到低填充，最多有一个分数项；取相应分界密度作为租金时，式 (P3) 取到式 (P2) 的值。因此参考实现得到的是这个松弛问题的最优上界及一个最优租金。所有正价值候选均能放入时可取租金 0；价格不一定唯一。

配合 I 的合法上界 \(\overline F(I)\)，得到整个搜索分支的上界。

**整数差距的反例。** 单链前缀累计收益为 0、1、3、6，容量为 2。原问题最多选前两块，收益 3；忽略前缀的松弛会选择单块贡献 3 和 2，得到上界 5。价格计算即使精确，也没有自动选出原问题的整数最优解。

因此式 (9) 的 Credit 正负仅描述给定价格下的合法操作净值；它不是独立逐块准入/淘汰的完备准则。

## 6. 跨轮 Lazy Refresh 的区间有效性

**引理 3：DAG 时间的扰动界。** 同一拓扑下，节点时间向量由 d 变为 d'，则：

\[
|D(d')-D(d)|\le \sum_v|d'_v-d_v|.
\tag{P4}
\]

证明：每条路径的时间变化绝对值都不超过右侧。任意一组函数的最大值变化，至多为各函数变化绝对值的最大值，所以 DAG 最长路径也满足该界。

比较相同前缀配置，README 式 (12) 的 \(E_w\) 同时控制所有场景下无备份和有备份的节点时间变化。由三角不等式：

\[
|F_w^{\rm new}(S)-F_w^{\rm old}(S)|\le2E_w.
\tag{P5}
\]

跨多轮但未刷新某缓存项时，逐轮应用三角不等式，得到 \(2\sum E_w\)。再与非负性和当前恢复时间上界取交，得到式 (13)。缓存项只保存计算时的值、当时累积扰动和工作流代次，不必在每轮遍历全部项。

同一工作流的新轮可能改变收益的任意方向，该证明都成立。拓扑、Agent 路径、相关场景成员或场景权重改变后，不再使用旧代次的区间。

实现的上界只需要扫描已给定的变化输入，不需要重新执行每个候选配置的 DAG；但当前 Python Model 构造和缓存更新仍包含输入扫描，不能据此推出常数总耗时。

## 7. 有界搜索与精确性

**命题 4。** 无预算限制时，solve 返回式 (7) 的最优可行集合及指定的确定性平局结果。

证明要点：

- 按森林拓扑顺序决定每个物理块的“保留/不保留”。保留子节点仅在父节点已保留时允许，容量超限的分支不生成，违反固定引用的分支不生成。
- 每个合法集合恰好对应这样的一条决定路径；没有合法选择被依赖规则遗漏。
- 每个待处理分支保存一个由引理 2、租金松弛和有效缓存区间构成的上界。
- 只有上界严格小于当前已知可行收益时才剪枝。等值分支保留以完成平局比较，因此不能丢掉更优值或更优平局解。
- 进入实际比较的配置使用当前版本的精确 DAG 值。Lazy 只改变计算时机和搜索顺序，不改变可行集合或目标。
- 有限树最终被访问或安全剪枝，最终结果即为枚举所有可行集合的最优结果。

提前停止时，所有尚未排除的解均在待处理分支中。因此：

\[
F(S_{\rm found})\le F(S^*)\le
\max\left(F(S_{\rm found}),\max_{\rm queue}\text{branch bound}\right).
\tag{P6}
\]

上式是最优性差距的证明，不是基于搜索时间或经验百分比估出的误差条。搜索预算为 0 时也必须返回可行起始解及有效上界。

### 7.1 有限预算模式允许保证什么

若当前状态仍然满足容量，在正常替换前精算当前/候选状态，且只提交 \(F(S')>F(S)\) 的候选，那么**同一固定版本的提交后状态**有严格更高的模型收益，即使 gap 尚未闭合。

这项保证不覆盖预测误差、切换窗口、下一轮输入或未来故障。输入未变、可行集合有限、只作严格改善时，不会在两个等价备份状态之间循环替换。输入变化后可能发生重新分配，这不受此有限状态论断禁止。

若容量已变小，保留当前状态可能不再合法；回收的首要保证是满足新容量与固定引用，不能继续要求收益提升。

## 8. 组件分解与整数动态规划

**命题 5。** 对物理父子/共享关系和整工作流依赖取连通组件后，各组件的物理字节数和 F 值均可相加。

证明：每个物理块只属于一个组件，所有前缀依赖都在该组件内。同一工作流引用的所有块被连接到同一组件，因此每个非零的工作流收益项只依赖一个组件的选择。没有 KV 的工作流增益恒为 0。

枚举每个组件的完整合法配置表。设前 i 个组件使用 b 字节时的最佳累计收益为 DP(i,b)，则：

\[
DP(i,b)=
\max_{q\text{ 为组件 }i\text{ 的合法配置}}
\{DP(i-1,b-b(q))+F(q)\}.
\tag{P7}
\]

按组件数归纳，即可证明该递推得到全局最优值。实现用稀疏的整数容量状态，不把容量向下取整，也不提交分数 chunk。

平局时采用的改变字节、新复制字节、占用字节均能按组件相加；组件位掩码不重叠，其数值也可相加。因此在同一容量状态只保留最佳词典序结果，不会损害后续组件的最优性。

配置表仅在结构、输入值、固定引用和可选对象完全匹配时复用。表不依赖本次总容量和当前备份；这两者在 DP/平局比较时使用。达到生成预算时，半张候选表不会作为完整表缓存。

### 8.1 计算复杂度不能隐藏

没有依赖、每个 Agent 属于独立工作流且只引用一块时，式 (7) 已包含普通 0–1 背包：令该块的恢复收益为物品价值、字节为重量即可。因此不能把一般精确求解描述为一次堆操作。

具有 g 个块的组件最坏有 \(2^g\) 个集合需要区分；共享和 DAG 耦合可能产生巨大组件。完整 DP 还取决于可达容量状态数与各组件配置数。有限预算控制的是计算工作，不自动提供一个固定比例的近似保证。

## 9. 物理事务的不变量

[protocol.py](protocol.py) 是单 Pool 的元数据参考，证明以调用者确实执行 DMA fence、发布当前版本、只发送正确 ACK 为前提。

1. **物理计费。** COMMITTED、COPYING、RETIRING 都计入实际分配；只有对应分配代次的 free ACK 才删除物理占用。
2. **先释放后分配。** 新分配只在所需受害块实际释放后执行，并再次核查 quota。复制本身不会制造超额分配。
3. **恢复可见性。** 先从恢复目录撤销受害后缀，再释放。新块只有全部必需分片 ACK 成功才整体发布为可恢复。
4. **前缀保持。** 撤销后保留的是两个合法集合的交集，因此仍合法；成功提交的目标预先经过合法性检查。
5. **版本一致。** 安全相关输入或容量改变使旧事务立即失效。纯价值更新可合并到当前合法事务之后发布，不改变该事务所用的已发布快照。迟到 copy ACK 不能重新发布已撤销事务。
6. **释放代次。** free ACK 同时匹配物理 ID 与分配代次。旧副本的迟到释放通知不能释放后续重新分配的同名副本。
7. **失败不虚构回滚。** 旧备份已经释放后，事务失败不会把旧备份重新标成存在；新副本释放完成前仍然占容量。

算法 3 若把 quota 降到当前物理占用以下，物理回收必然有延迟，所以此时不声称“占用始终不超过新 quota”。保证是停止新增分配、发起合法回收、收到 ACK 后收敛到新上限。若固定引用本身超过上限，应报告暂时不可行。

## 10. 明确没有证明的内容

- 当前时间预测与真实恢复 WCT 一致。
- 当前最优备份分配也是未来请求序列或未来所有故障上的最优策略。
- 继承经典 Landlord 的竞争比、次模 greedy 的近似比，或者租金价格本身解决整数问题。
- 任意共享规模下能够在固定微秒预算内完成。
- 旧累计 L 与逐 Agent 分账续租已经被式 (9) 实现。

这些限制不是用更多 Credit 权重可以消除的问题。它们分别对应代价校准、在线目标、结构假设、求解规模和算法语义，需要各自的论证与实验。
