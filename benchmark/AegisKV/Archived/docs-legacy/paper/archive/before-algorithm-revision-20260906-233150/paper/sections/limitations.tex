\section{Limitations and Validity}
The workload prescribes durations, output counts and static dependencies;
it does not validate dynamic topology discovery, answer quality or long-context
prediction. Ideal Slack, prompt-only protection, coarser allocations and
uncalibrated software/device timing limit extrapolation. The physical pilot
covers one process failure per arm, not pressure-reclaim races, streaming,
TP/PP recovery, control-plane loss or partitions.

Five admission permutations provide limited resolution for one finite
workload. Policy-dependent collateral victims and a small set of logical
fault positions limit external validity. Intervals are exploratory, with no
multiplicity correction or worst-case reliability guarantee. Replacement
gaps, shared-ordinal sealing and request salts can reduce redundancy and
reuse; faster restoration alone need not improve the workflow.

\paragraph{Use of AI tools.}
Generative AI tools assisted source inspection, code editing, figure
production and manuscript drafting. Quantitative values are computed from
the identified datasets and execution artifacts.
