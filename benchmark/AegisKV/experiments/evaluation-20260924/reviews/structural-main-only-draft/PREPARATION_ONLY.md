# Review draft, not a campaign

This directory contains an unmerged runner/audit/plot draft. The preparation-check directories execute only workload generation and source/input freezing checks. Their snapshots are disposable preparation evidence from a runtime still under review, not approved experiment sources. Their runs directories must remain empty. No new simulation or figures are generated here.

`run_structural_campaign.py prepare --main-only --out NEW_PATH` prepares 135 main cases; omitting the flag retains the original 143-case matrix. Subsequent run/summarize commands obey the sealed plan. Passing --main-only to a pre-existing full plan fails rather than silently filtering it. PLAN_SEAL.json binds the plan/manifest before execution; completed records additionally bind each canonical job.

The 135 cases preserve scenario/seed/policy/fault, fixed role priors, explicit 16384 output cap, provider, original DAG once, logical fault identity, detailed-log choices, L4/K16 and all model parameters. The current Config schema adds explicit slack_mode="dag", equivalent to the old frozen runtime's unconditional DAG Slack. This is reported as an added schema field, not falsely claimed to be byte-identical JSON. All other job fields and decoded workload hashes must match exactly. A future corrected runtime source is intentionally different and must receive a fresh independent freeze after the queued-history fix passes.

`audit_result_details.py --out CAMPAIGN` audits all 135 or 143 cases according to the plan. --main-only can additionally audit the complete 135 subset of a 143 plan, leaving campaign status PARTIAL; a sealed 135 main-only plan itself is COMPLETE after all its cases pass. Draft post-execution audit support awaits actual corrected summaries; preparation checks are not an execution audit.

`plot_structural_campaign.py --source CAMPAIGN` supports both plan counts. It prepares target and all-workflow WCT views from the same F1-minus-own-policy-F0 paired delta. All-workflow points average eight workflow deltas within a run first; they do not turn dependent workflows into independent seeds. The three seeds remain the statistical units for displayed min/max and means. Descriptive p95/p99 of paired deltas remain separate from differences of percentile WCTs. There are no confidence intervals. The new all-workflow view has not been drawn or visually reviewed; final-size color/grayscale review is required once corrected data exist.

No changes in this draft affect the original 143-run snapshot, its ongoing n128 processes, or frozen figures.
